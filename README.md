# Sleep-Talk-Ai 🧠💬

A Streamlit-based AI chatbot for interpreting user-submitted dreams using NLP and a curated dataset.

## 🚀 Features
- NLP-powered keyword extraction using spaCy
- Dataset-driven response engine
- Groq API fallback for unmatched dreams
- Simple and clean Streamlit UI
- Lightweight local deployment

## 🛠 Technologies Used
- Python
- spaCy
- Pandas
- Streamlit
- Groq API (optional fallback)
